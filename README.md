# HTML-site-my-document

Personal HTML project for publishing and presenting Danila's long-form AI documentation.

## Repository purpose

This repository is the web-facing layer of the project: HTML/CSS/JavaScript and related static assets belong here.

## Working principles

- Keep the site structure simple and inspectable.
- Prefer small, readable commits.
- Do not store secrets, API keys, tokens, or private credentials in the repository.
- Preserve source materials and document provenance when adding generated content.

## Current integration

This repository is connected to an AI-assisted GitHub workflow, so repository files can be inspected and updated through the configured GitHub integration.
